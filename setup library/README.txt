KierCRUD Library Portable Setup

1. Copy this entire "setup library" folder to a USB flash drive.
2. On the destination Windows PC, make sure .NET 8 and MySQL are installed.
3. Make sure MySQL listens on localhost port 3307.
4. Double-click setuplib.cmd.
5. The installer copies the library to %LOCALAPPDATA%\KierCRUD\Library and creates a desktop launcher.

The application creates or updates the library database automatically on first start.
The current penalty rate is 10 pesos per overdue day. Existing loans are preserved.
