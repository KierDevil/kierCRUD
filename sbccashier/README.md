# SBC Cashier

Standalone student cashier and registrar system. It is separate from SES, SCSDS, and Library.

Run from `C:\kierCRUD`:

```powershell
.\STARTWEBSBCCASHIER.cmd
```

Open http://localhost:5195.

Supports student ID, course, year level, tuition payments, vehicle passes, registrar documents, COR, COE, Student ID, other requests, cash/card payments, and MySQL persistence in the `sbccashier` database.
